# Aurum — marketplace (maquette)

Maquette de marketplace multi-vendeurs **Aurum** (« L'Excellence à votre portée ») en pages HTML statiques.

## Pages

Accueil, catalogue, produit, panier, commande, facture, favoris, connexion et inscription, espace vendeur, administration, restaurant, à propos, FAQ, contact, CGU. Le site est prêt pour le référencement (`sitemap.xml`, `robots.txt`) et installable (`manifest.json`).

## Lancer

Ouvrir `index.html` dans un navigateur.

Vérification rapide avec Playwright (voir [`README_PLAYWRIGHT.md`](README_PLAYWRIGHT.md)) :

```bash
npm install
npm run test:playwright
```

Une version plus aboutie, avec JavaScript modulaire et documentation, se trouve dans le dépôt [`Ghost`](https://github.com/darenallan/Ghost).
